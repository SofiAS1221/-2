# Vue.js Auth Application (Test Task)

Учебное приложение на Vue 3, реализующее систему авторизации, защищенные роуты и взаимодействие с внешним API. Проект выполнен на основе макета Figma и использует DummyJSON в качестве бэкенда.

## 🚀 Функционал
##  Функционал

- Главная (Home): Приветственная страница с описанием.
- Пользователи (Users): Публичный список пользователей, полученный через API.
- Авторизация (Login): Форма входа с валидацией на стороне сервера.
- Профиль (Profile): Приватная страница, доступная только после входа (используется Navigation Guard). Данные подгружаются по токену.
